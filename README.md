CS50: Introduction to Computer Science
Harvard University's Legendary Computer Science Course

This is CS50x, Harvard University's introduction to the intellectual enterprises of computer science and the art of programming. Whether you're a complete beginner or have some coding experience, this course will teach you how to think algorithmically and solve problems efficiently.​

About This Course
CS50 is Harvard's largest course, taught by Professor David J. Malan. An entry-level course designed for majors and non-majors alike, with or without prior programming experience. In fact, two-thirds of CS50 students have never taken a computer science course before.​

What You'll Learn
Computational Thinking: Learn to think methodically and solve problems efficiently

Multiple Programming Languages: C, Python, SQL, JavaScript plus HTML and CSS

Core CS Concepts: Algorithms, data structures, abstraction, encapsulation, resource management, security, and software engineering

Web Development: Build web and mobile applications

Real-World Problem Sets: Inspired by biology, cryptography, finance, forensics, and gaming domains

Course Structure
10-Week Curriculum
Week 0: Scratch - Introduction to programming using a visual language
Week 1: C - Low-level programming fundamentals
Week 2: Arrays - Working with data structures in C
Week 3: Algorithms - Searching, sorting, and computational efficiency
Week 4: Memory - Pointers, dynamic memory, and file operations
Week 5: Data Structures - Linked lists, trees, hash tables, and tries
Week 6: Python - Transitioning to high-level programming
Week 7: SQL - Database management and queries
Week 8: HTML, CSS, JavaScript - Web development fundamentals
Week 9: Flask - Building web applications
Week 10: Final Project - Design and implement your own project

Learning Objectives
By the end of this course, you will be able to:

Think algorithmically and solve programming problems efficiently

Program in multiple languages and teach yourself new ones

Read documentation and specifications

Test solutions, identify bugs, and handle edge cases

Assess code correctness, design, and style

Apply computer science to problems in various domains

Course Requirements
10 problem sets (programming assignments)

10 lab sessions

1 final project

Average time commitment: 10-20 hours per week

Self-Paced Learning
This is a self-paced course available year-round. Complete it on your own schedule through platforms like edX and freeCodeCamp
